# Noto Sans TC subset

`research-tc.woff` is a locally hosted variable font subset of Noto Sans TC, generated with fontTools from the installed `NotoSansTC-VF.ttf`. Original copyright: © 2014–2021 Adobe, with Reserved Font Name “Source”. Licensed under SIL Open Font License 1.1; see `OFL-NotoSansTC.txt` (from the official google/fonts `ofl/notosanstc` directory).

The subset includes characters present in this site's HTML, JavaScript and JSON, refreshed for the leaderboard polish, plus ASCII. No glyph shapes were changed. The internal family remains Noto Sans TC; CSS uses the local alias `Research TC`. Weights remain variable. Missing characters fall back to the system CJK font. The site makes no runtime font request to Google.

Source license: https://github.com/google/fonts/blob/main/ofl/notosanstc/OFL.txt

The generation script for this revision is archived in the workspace at `artifacts/wallet-redesign/subset-font.py`.
