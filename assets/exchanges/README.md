# Exchange brand assets

Original public brand icons from the exchanges' official websites, app icons, or media kit. Files are stored locally so third-party requests are not required when reading the comparison page. No recoloring or generated replacements.

`sources.json` records the official discovery page, original asset URL, retrieval date, size, and SHA-256. Gate's official media-kit SVG was downloaded through the browser because direct scripted requests returned 403. Brand ownership remains with each exchange; use here identifies the subject of the comparison and does not imply endorsement.
