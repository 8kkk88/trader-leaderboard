資料口徑與計算方式

這是本批樣本，不是全鏈實力排名

Birdeye 先依總損益篩出有限錢包樣本，本頁再在同一期間、同一批資料內排序。預設按已實現收益由高到低；同值時按總損益，其次按地址。切換總損益時，次排序則為已實現收益。交易次數與成交量可用來比較，不能單憑它們認定身份或交易能力。

總損益、已實現與落袋比例

總損益使用 pnl，已實現收益使用 realized，兩者不等於未實現損益 unrealized。

落袋比例 = realized / pnl × 100%，僅在兩欄皆有數值且 pnl > 0 時適用。可為負值，也可高於百分之百；它不是勝率、提款比例或完成度。本頁僅呈現文字比例，不以長條限制數值。

本期觀察與紙上富貴標籤

本期觀察取所選期間總損益最高、具有效總損益數值的前十個錢包，計算其中 abs(realized) < 1 的個數；小於一美元不等於真零。缺值不納入近零計數，會另行註明。

「紙上富貴」條件維持 abs(realized) < 1 && pnl > 100000；這只是資料條件，不代表未曾賣出。另一種排名是同批樣本的排序比較，並非昨日名次。

缺值與金額顯示

前端收到的缺值顯示「—」，但抓取程式已將部分 API 缺值轉成零，單靠 data.json 無法還原真零與缺值的差別。上游口徑仍待處理。

金額一般四捨五入至整美元；非零且絕對值低於一美元時保留小數。比例一般顯示至小數一位，接近零或略高於百分之百時提高精度；這些都是顯示格式，不會改寫原始值。
