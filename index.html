WHY / 建站初衷

這個站是怎麼來的？

你有沒有看過那種交易員排行榜，上面清一色都是漂亮的帳面獲利？問題是，沒賣掉都還不算落袋啊。只照著帳面數字跟單，可能最後才發現自己跟了個「紙上富貴」。

我想先看一種錢：已經賣掉、實現的收益。一個錢包帳面再漂亮，如果看不到對應的已實現收益，那他到底會不會賺錢，光看帳面誰知道？

所以這個榜單預設按「已實現收益」排序，再把總損益放在旁邊，讓你自己對照。資料只取 Birdeye 公開樣本，我不裝作看得到全鏈，看不到的會老實講。

「紙上富貴」是依本批數值條件標記，不代表已查證錢包從未賣出。

怎麼算？有哪些限制？

估算落袋損益＝（賣出單價 − 買入單價）× 成交數量 − 費用合計。

假設輸入數量全數成交。費用請自行加總買賣手續費與其他成本；不同批次成本、槓桿、利息與稅務不在本工具範圍。這是依輸入做的試算，不是錢包實際收益紀錄。

術語，換句話說。

先弄懂這些詞，再看數字就有方向。

已實現損益

已賣出部位對應的損益。賣出收入扣掉該部位成本，才知道實際賺或賠；費用是否已扣，還要看來源口徑。

未實現損益

還持有的部位，按當下估價計算的帳面損益。價格會變，尚未賣出就不代表已經落袋。

總損益

同一來源、同一統計期間的已實現與未實現損益合計。總損益漂亮，可能主要來自尚未賣出的帳面收益。

快照

把某個時間點取得的資料保留下來，方便之後比較。它是一張定格畫面，不是即時行情；請看來源時間。

樣本

這一批實際取得、收錄來比較的錢包。樣本內排名不等於全鏈排名，未收錄的錢包也不代表表現不好。

資料口徑與計算方式

這是本批樣本，不是全鏈實力排名

Birdeye 先依總損益篩出有限錢包樣本，本頁再在同一期間、同一批資料內排序。預設按已實現收益由高到低；同值時按總損益，其次按地址。切換總損益時，次排序則為已實現收益。交易次數與成交量可用來比較，不能單憑它們認定身份或交易能力。

總損益、已實現與落袋比例

總損益使用 pnl，已實現收益使用 realized，兩者不等於未實現損益 unrealized。

落袋比例 = realized / pnl × 100%，僅在兩欄皆有數值且 pnl > 0 時適用。可為負值，也可高於百分之百；它不是勝率、提款比例或完成度。本頁僅呈現文字比例，不以長條限制數值。

新進樣本與已落袋

首頁「本次新進樣本」比較最近兩份完整快照：最新單日樣本有、前一份沒有的地址。不代表今天才建立錢包，也不代表首次在歷史或全鏈榜單出現。兩份來源時間列在三卡下方。

條件實驗室的「已實現收益大於零」只計入所選期間 realized > 0 的錢包，與新進樣本是不同指標。

本期觀察與紙上富貴標籤

本期觀察取所選期間總損益最高、具有效總損益數值的前十個錢包，計算其中 abs(realized) < 1 的個數；小於一美元不等於真零。缺值不納入近零計數，會另行註明。

「紙上富貴」條件維持 abs(realized) < 1 && pnl > 100000；這只是資料條件，不代表未曾賣出。另一種排名是同批樣本的排序比較，並非昨日名次。

缺值與金額顯示

前端收到的缺值顯示「—」，但抓取程式已將部分 API 缺值轉成零，單靠 data.json 無法還原真零與缺值的差別。上游口徑仍待處理。

榜單與首頁的美元金額統一顯示至小數兩位；非零且小於一美分的值保留必要精度，避免看成零。比例一般顯示至小數一位，接近零或略高於百分之百時提高精度；這些都是顯示格式，不會改寫原始值。
