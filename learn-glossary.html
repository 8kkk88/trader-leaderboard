正經術語

術語大白話解釋
DYOR自己研究和核驗，不把別人意見當作結論
FOMO怕錯過機會，從而衝動參與
FUD恐懼、不確定與懷疑；不能用這個詞否定一切質疑
HODL社群表達長期持有的說法
ATH / ATL歷史最高價 / 歷史最低價；留意資料範圍
Bull / Bear看漲 / 看跌，也可指牛市 / 熊市
Whale持倉或交易規模較大的參與者
Degen對高風險玩法很激進的參與者，常帶自嘲
Rug Pull專案方透過撤走資金或其他方式拋棄參與者的跑路行為
Honeypot看似能買入，卻可能限制賣出或轉移的陷阱
Airdrop空投，向符合條件的使用者或地址分配資產
Snapshot快照，按某個時點記錄狀態
Vesting按時間或條件逐步釋放資產的安排
TGE代幣生成事件，具體是否立即流通取決於規則
Whitepaper白皮書，專案的設計與方案說明，不是兌現保證
Tokenomics代幣經濟，包括髮行、分配、用途與激勵
TVL總鎖定價值，需要看統計範圍與口徑
FDV完全稀釋估值，需要看供應量口徑
Gas交易執行所需網路資源或費用的常用說法
TxID交易標識 / 雜湊，用於查詢交易
Approve授權，允許指定物件按規則使用資產
Revoke撤銷相關授權，不能追回已經損失的資產
Slippage滑價，預期與實際成交價格的差異
LP流動性提供者，也常用於表示流動性部位
MEV最大可提取價值，涉及交易排序、包含或排除等機會
CEX / DEX中心化交易所 / 去中心化交易協議或場所
KYC身分驗證流程
P2P使用者之間的交易模式，幣圈常用於法幣買賣
Long / Short做多 / 放空
Funding Rate永續合約資金費率
Liquidation清算 / 強平，具體含義看場景
GM / GN社群打招呼：早安 / 晚安
莊家 / 市場操縱俗稱「狗莊」。指持有大量籌碼、能明顯影響某個幣價格或成交的人或團體，可能透過集中買賣、刷量、拉高後出貨等方式影響價格；小市值、流動性差的幣更容易被操縱
Meme 幣圍繞文化、社群和傳播的代幣，小市值高風險的常被叫作「土狗」；可能暴漲，也可能快速歸零或賣不出去
Swap兌換 / 換幣，把一種資產換成另一種，注意價格影響、滑價與網路費
Private Key私鑰，授權帳戶操作的秘密資訊；和助記詞一樣，絕不交給任何人
MPC 錢包多方計算錢包，把金鑰分成多個分片分開儲存，建立時通常不用抄寫傳統助記詞（例如幣安錢包（無私鑰））；仍要完成備份並確認恢復方式
WAGMI「我們都會成功」的社群口號，不是回報保證
