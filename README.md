# 鏈上交易員實力榜

Solana 鏈上交易員排行榜，主打「已實現收益」視角——沒賣出都不算賺。

- 資料來源：Birdeye 公開 API（`/trader/gainers-losers`），每小時更新
- 頁面：`index.html`、`styles.css`、`app.js`（靜態網站，無建置依賴；明亮／深色模式，桌面表格、手機卡片）
- 預設按本批樣本的已實現收益排序，可切換總 PnL 排序；`abs(realized) < 1 && pnl > 100000` 標「紙上富貴」，不代表已驗證從未賣出
- 研究室：`research.js` 提供正收益／最低交易次數篩選、雙錢包對比、每週研究題、瀏覽器草稿與手動分享；沒有站內公開留言。分享連結讀取最新快照，當時證據可複製成文字。
- 產品工作台：`product.js` / `product.css` 提供排行榜、交易員對比、每週研究、資料說明四個獨立查詢網址；支援手機底部導覽、桌面頂部導覽與瀏覽器歷史。舊的研究室錨點連結仍相容。
- 數據管線：`fetch.py` → `data.json` → `sync.sh` 每小時 commit+push（無變化跳過）
- 排程：`trader-leaderboard-sync.timer`（systemd，每小時）

本頁僅為數據整理與教學，不構成投資建議。

## 共用產品框架

所有工作區共用 `shell.js` 的品牌、圖示、桌面／平板頂部導覽、手機底部導覽與明暗模式。首次造訪預設淺色；`shell.js` 在 head 提早套用已保存的明暗偏好，並保留跨分頁 storage 同步。`product.js` 與 `wallets.js` 載入後建立相同框架。新增工作區請擴充共用 routes，不要另外複製 header 或主題邏輯。

共用排版位於 `product.css`，新商務視覺的明暗 token、字體與導覽樣式統一由 `design-system.css` 定義，各工作區只補自身內容版型。中文使用自託管 Noto Sans TC 字型子集，字型來源與授權見 `assets/fonts/RESEARCH-TC.md`。交易員對比與 Web3 錢包比較明確區分命名。手機導覽使用短標籤，保留完整 accessible name。

## Web3 錢包比較

`wallets.html` 讀取同目錄 `wallets.json`，使用獨立的 `wallets.css` / `wallets.js`。資料以已審核附件為基礎；獎勵欄依發文前重查結果修正，逐家來源與查證限制見 `WALLETS-REWARDS-RECHECK.md`。基準日由 JSON 讀取；不呼叫錢包 API，也不需要任何密鑰。啟動靜態 HTTP server 即可預覽，請勿直接使用 file:// 開啟。

表格預設顯示 Tier 1，可切換全部、操作任意欄位排序、點開 hint 與格子詳細說明。數值來源為 JSON；缺失 hint 僅補介面說明，不補數據。單一數值按數字；費率區間取最高揭露值、部分免收取一般費率；複合顯示值及安全資訊按文字排序。未揭露與待查證始終置後；安全欄沒有綜合評分或安全排名。

未保存偏好時，預設為錢包名稱＋Swap 抽成、公鏈數、密鑰／登入方式、硬體支援四個維度。「自訂欄位」可逐項勾選所有維度、全選或恢復常用欄位；至少保留一個比較欄位，錢包名稱固定顯示。表格下方可展開全部維度，收合時還原展開前的選擇。取消／Escape 不改動目前選擇。套用後僅將欄位 key 保存在本機 `research-wallet-columns-v1`，重新整理與切頁後還原；既有使用者的選擇會保留，無效／已移除 key 會忽略，儲存不可用時仍能在當次頁面使用。若隱藏排序欄位，回到資料順序。

錢包官方圖示保存在 `assets/wallets/`，來源與原始檔雜湊見 `sources.json`。前端不向第三方圖片伺服器發請求，圖示保留原色及比例；手機也顯示 logo。圖示失敗時顯示名稱首字母。A／B／C 來源標記改為單色；未知值以灰字呈現，展開後仍能查看來源類型。資料檔 schema 與內容未修改。

小測驗採逐題流程，顯示進度、必填提示，可返回修改及重新作答。推薦規則沿用：先排除不支援所選鏈或硬體需求的錢包，再依新手登入方式／老手開源偏好配對；同分優先 Tier 1，再依附件順序，最多呈現兩個。配對理由只引用附件功能，不表示安全性或報酬推薦。硬體型號仍需另外核對。
