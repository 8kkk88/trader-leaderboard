# 鏈上交易員實力榜

Solana 鏈上交易員排行榜，主打「已實現收益」視角——沒賣出都不算賺。

- 資料來源：Birdeye 公開 API（`/trader/gainers-losers`），每小時更新
- 頁面：`index.html`、`styles.css`、`app.js`（靜態網站，無建置依賴；明亮／深色模式，桌面表格、手機卡片）
- 預設按本批樣本的已實現收益排序，可切換總 PnL 排序；`abs(realized) < 1 && pnl > 100000` 標「紙上富貴」，不代表已驗證從未賣出
- 研究室：`research.js` 提供正收益／最低交易次數篩選、雙錢包對比、每週研究題、瀏覽器草稿與手動分享；沒有站內公開留言。分享連結讀取最新快照，當時證據可複製成文字。
- 產品工作台：`product.js` / `product.css` 提供排行榜、錢包對比、每週研究、資料說明四個獨立查詢網址；支援手機底部導覽、桌面側欄與瀏覽器歷史。舊的研究室錨點連結仍相容。
- 數據管線：`fetch.py` → `data.json` → `sync.sh` 每小時 commit+push（無變化跳過）
- 排程：`trader-leaderboard-sync.timer`（systemd，每小時）

本頁僅為數據整理與教學，不構成投資建議。

## 共用產品框架

所有工作區共用 `shell.js` 的品牌、圖示、桌面側欄、平板頂部導覽、手機底部導覽與明暗模式。`shell.js` 在 head 提早套用已保存／系統主題；`product.js` 與 `wallets.js` 載入後建立相同框架。新增工作區請擴充共用 routes，不要另外複製 header 或主題邏輯。

共用排版與字級位於 `product.css`，各工作區只補自身內容版型。交易員對比與 Web3 錢包比較明確區分命名。手機導覽使用短標籤，保留完整 accessible name。字體、按鈕、狀態色與資料仍沿用原有系統。

## Web3 錢包比較

`wallets.html` 讀取同目錄 `wallets.json`，使用獨立的 `wallets.css` / `wallets.js`。資料以已審核附件為基礎；獎勵欄依發文前重查結果修正，逐家來源與查證限制見 `WALLETS-REWARDS-RECHECK.md`。基準日由 JSON 讀取；不呼叫錢包 API，也不需要任何密鑰。啟動靜態 HTTP server 即可預覽，請勿直接使用 file:// 開啟。

表格預設顯示 Tier 1，可切換全部、操作任意欄位排序、點開 hint 與格子詳細說明。數值來源為 JSON；缺失 hint 僅補介面說明，不補數據。單一數值按數字；費率區間取最高揭露值、部分免收取一般費率；複合顯示值及安全資訊按文字排序。未揭露與待查證始終置後；安全欄沒有綜合評分或安全排名。

欄位預設為 Swap 抽成、公鏈數、Solana、硬體支援與密鑰／登入方式。「自訂欄位」可逐項勾選所有維度、全選或恢復常用欄位；至少保留一個比較欄位，錢包名稱固定顯示。取消／Escape 不改動目前選擇。套用後僅將欄位 key 保存在本機 `research-wallet-columns-v1`，重新整理與切頁後還原；無效／已移除 key 會忽略，儲存不可用時仍能在當次頁面使用。若隱藏排序欄位，回到附件順序。

錢包官方圖示保存在 `assets/wallets/`，來源與原始檔雜湊見 `sources.json`。前端不向第三方圖片伺服器發請求，圖示保留原色及比例；手機也顯示 logo。資料檔 schema 與內容未修改。

小測驗先排除不支援所選鏈或硬體需求的錢包，再依新手登入方式／老手開源偏好配對；同分優先 Tier 1，再依附件順序，最多呈現兩個。配對理由只引用附件功能，不表示安全性或報酬推薦。硬體型號仍需另外核對。

驗證：逐格比對全部 108 格 display/detail/來源分級；測試所有欄位雙向排序、12 組小測驗、HTTP 錯誤／資料格式錯誤與重試。瀏覽器檢查 320、375、390、844、1440px，確認手機橫滑、固定錢包名稱、首頁導覽互連且無整頁水平溢出。完整紀錄在工作區 `artifacts/wallet-comparison/output/playwright/`。
