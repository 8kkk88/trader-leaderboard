助記詞與私鑰：不分享、不上傳

助記詞誰要都不給，客服也不會要。

不傳送給客服、朋友、專案方、AI 或任何表單。不拍照上傳網盤，不復制到聊天工具或線上筆記。使用錢包官方支援的離線備份方法，並考慮火災、進水、遺失與他人接觸風險。

正規客服不需要你的助記詞來幫你查交易。任何人索要它，都應停止溝通。

假官網與假 App

搜尋和廣告裡的連結可能是假的，只用收藏好的官方入口。

搜尋結果、廣告位、社交帳號和群置頂都可能出現仿冒連結。檢查完整域名，從可信的官方渠道交叉確認，收藏已核驗入口。

下載應用檢查開發者與來源，不安裝陌生人私發的安裝包。硬體錢包從官方或可核驗渠道購買，不使用別人預先設定好的助記詞。

連線、簽名與授權不是一回事

連線、簽名與資產授權是不同操作，不能只看頁面上的按鈕名稱。

連線錢包通常是讓應用識別地址與請求權限，並不自動意味著資產被轉走。
簽名是對資訊或操作的確認；有些鏈下簽名也可以授權後續資產轉移，不能把「不收 Gas」當作無風險。
授權是允許某個合約按條件使用資產，例如 ERC-20 代幣額度。不同網路與資產有不同權限機制。

看不懂請求內容，就不確認。不要盲籤，也不要相信頁面標題寫著「登入」就一定只是登入。

理解 Permit 類簽名的作用

部分協議可利用鏈下簽名授權後續代幣操作。簽名當下沒有支付 Gas，不代表之後不會發生資產轉移。

用什麼工具輔助檢查簽名？

安全外掛能幫你提醒，但最後還是要自己看懂。

GoPlus 可以用來查授權、撤授權，也提供瀏覽器擴充套件，在支援的場景中輔助提示可疑請求。它只能查授權、撤授權和輔助提醒，不能保證資產不被盜。錢包自身提供的模擬交易與風險提示，也值得檢視。

GoPlus 官網入口：https://gopluslabs.io/en

從官網進入瀏覽器擴充套件頁面，核對釋出者、相容錢包、網路、權限與當前支援範圍。簽名解碼 API 與瀏覽器外掛不是同一個功能，不能假設外掛支援每條鏈、每種簽名。

工具提示只是輔助判斷，沒有出現警告也不代表一定安全。仍需核對交易對象、資產變化與授權範圍，任何檢查都不需要把助記詞交給工具。

斷開連線不等於撤銷授權

斷開連線後，授權還在，要單獨撤銷。

斷開網站連線只改變連線關係。已存在的鏈上授權仍然有效，需要按對應鏈與錢包的方法單獨檢查和撤銷。

撤銷可能需要網路費，也不保證恢復已經轉走的資產。如果助記詞或私鑰洩露，僅撤銷授權不足以解決問題。

無限授權

無限授權可能擴大相關代幣的可動用範圍，不代表損失金額字面上無限。

無限授權允許被授權物件使用很大的代幣額度，不必每次重新批准。它更方便，也可能擴大合約漏洞或惡意權限造成的損失。優先理解權限範圍，按需求授權。

常見騙局

索取助記詞是明確警訊；簽名或付費請求則需要核對用途、物件與權限。

  • 假空投：先讓你簽名、授權或支付費用。
  • 假客服：主動私信，讓你下載遠端軟體或交出恢復資訊。
  • 假投資群：展示盈利截圖，要求轉入指定平台。
  • 不能提領：讓你繼續繳稅、解凍費、保證金才能提領。
  • 假回收與找回：宣稱被盜資金一定能追回，先收錢。
  • 地址投毒：在交易記錄裡放相似地址，誘導複製。
  • 惡意代幣與 NFT：名稱或備註裡帶領取網址，誘導訪問。
  • 剪貼簿劫持（也常被叫作貼上板攔截）：惡意程式把剛複製的收款地址換成攻擊者地址。
  • 第三方應用讀取剪貼簿：應用或外掛會讀取你複製過的內容；若其中有恢復資訊、密碼或金鑰，就會洩露。不同系統的權限和提示機制不同。

陌生資產出現在錢包裡，不等於你必須處理。不要因為顯示「價值很高」就訪問其中的連結。

中文社群常見的詐騙情境

不明來源的收款、假投資平台與借用帳戶，都可能帶來嚴重風險。

不明來源款項與帳戶凍結

P2P 收到與詐騙有關的款項，可能引發銀行或平台審查。核對本人帳戶與訂單資料，不接受不符合平台規則的第三方付款，也不替別人代收。平台認證商家並不代表交易必然沒有風險。

假交友與假投資

詐騙者可能先建立感情或群組信任，再引導到假平台，甚至先讓人提領小額資金。小額成功提款、獲利截圖與熟悉感，都不能證明平台真實。

高價收幣與代收轉帳

借用銀行卡、交易所帳戶或錢包代收轉帳，可能使你捲入不法金流。原文提及中國大陸的特定罪名；本版不把這些罪名套用到其他地區。法律責任依所在地與個案事實而異，遇到可疑情況應儲存資料，向當地警方或專業人員查證。

防止剪貼簿洩露

助記詞和私鑰永遠不要複製貼上。

不要把助記詞、私鑰、API 金鑰等複製到剪貼簿，不貼上進聊天、AI、線上筆記或網頁。密碼優先使用可信密碼管理器的自動填充方案。

移除不需要或來源不明的應用、鍵盤和瀏覽器擴充套件，檢查可用的剪貼簿、輔助功能及裝置權限。關閉不需要的剪貼簿歷史、雲同步或跨裝置共享，保持系統更新。

清空剪貼簿可以減少後續讀取，但不能撤回已經被讀取的資訊。懷疑秘密資訊洩露時，需要更新相應憑證；助記詞或私鑰洩露則應按第 15 章處理。

地址被替換的防範步驟，見第 10 章「轉幣前四項檢查」。

帳戶與裝置保護

保護好郵箱和手機，就保護了大半個帳戶。

保護郵箱、使用獨立密碼與可靠的雙重驗證，更新系統和錢包，不安裝不明外掛，不共享螢幕上的恢復資訊。交易所開啟可用的提領白名單與登入提醒。

API 金鑰也是秘密。未來需要自動化時，使用最小權限；交易機器人通常不需要提領權限。不要把金鑰發給陌生機器人或公開到程式碼倉庫。

隱私也需要保護

鏈上轉帳大家都看得到，錢包沒有實名也能被追蹤。

鏈上交易在很多公鏈上可公開查詢。公開地址可能關聯餘額、行為和身分。錢包不顯示實名，不代表無法追蹤。
